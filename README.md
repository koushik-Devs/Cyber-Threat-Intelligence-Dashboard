# Cyber Threat Intelligence Dashboard

This project provides a **live cyber threat intelligence dashboard** using open-source threat data from AlienVault OTX, processed in Python and visualized using **Power BI**.

## 🔍 Project Overview

The goal is to automate the retrieval, processing, and visualization of trending global cyber threats using live CTI feeds. The dashboard helps analysts, security teams, and SOC operators monitor threats in real-time.

---

## 🛠️ Features

- ✅ Fetches latest CTI feeds from AlienVault OTX
- ✅ Parses and stores pulse metadata into CSV
- ✅ Power BI dashboard visualization
- ✅ Highlights trending threat actors, IOCs, malware names, and attack categories
- ✅ Automated pipeline (extendable for real-time alerts)
